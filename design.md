# Design Guidelines

This document contains design references and guidelines to ensure consistency across the application.

## Forms

Use this page as reference for design of forms in admin panel:
- **Reference URL**: `http://localhost:3000/admin/municipality/youth/create`

When creating or updating forms in the admin panel, follow the design patterns established on this page.

## Avatars

- **Shape**: Avatars should be **rounded (circle)**, not square
- Always use circular avatars throughout the application

## Icons

- **Background**: Do not use gradient backgrounds, only **flat colors**
- **Color**: Icons within a colored background should be **black in color**

## Buttons

Follow these color and text color rules for buttons:

- **Primary color buttons**: If a button has primary color as background color, then make the text color **black**
- **Green buttons**: Should have **black text color**
- **Dark buttons**: Should have **white text color**
- **Light buttons**: Should have **black text color**
